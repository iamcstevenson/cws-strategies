# CWS Strategies website

One-page site for CWS Strategies (trade name of CWS, LLC), served by GitHub Pages at https://cherlynnstevenson.com.

- `index.html` — the whole page (styles inline; fonts self-hosted in `fonts/`)
- `CNAME` — custom domain for GitHub Pages
- `deploy.py` — optional: commit + push + Pages setup from a Mac with the `gh` CLI

Every push to `main` republishes the site.
